# radlex-links

The routing page behind the single QR code on the RSNA 2026 RadLex Committee poster. GitHub Pages serves `index.html` from the `main` branch at <https://hoodcm.github.io/radlex-links/>.

To change a link, edit its `href` in `index.html` and push to `main`. The printed QR code encodes only the site address, so the links can change after the poster prints.
